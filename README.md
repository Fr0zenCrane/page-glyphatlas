# GlyphAtlas project page

Project page for **GlyphAtlas: Disentangling Stroke Detail from Layout for Scene Text Synthesis**.

**Authors:** Luozheng Qin, Changhai Zhou, Yiyi Zhou.

The Method section presents the framework and its main contributions, followed by the atlas construction procedure. Four results sections follow:

1. Accurate Scene Text Generation and Editing
2. Zero-Shot Transfer Across Scripts
3. Qualitative Comparison Results
4. Component Ablations and Atlas Budgeting

The five tables follow the paper. Figures open at full resolution, and tables scroll horizontally on mobile. Paper and Model have placeholders in the resource links; Code and Dataset link to their repositories.

## Preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. The page uses static HTML, CSS and JavaScript.
